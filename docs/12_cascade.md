## この回のゴール

## 1. 直感クイズ ―― 行列のできる店

2軒のラーメン店。本当はどちらが美味しいか分からない。通りかかった人が1人ずつ「どちらに入るか」を決めていく。各人は ①自分なりの **私的な勘**（完璧ではないが五分よりは当たる）と、②**先に並んでいる人数**（他人の選択）を見て決める。

あなたが店Aに並ぶと、次の人には「Aに○人並んだ店」に見える。これが続くと集団はどうなるか？

## 2. モデル ―― 私的な情報 vs 他人の行動

古典的な「壺と玉」のモデルで考える。

- 正解（本当に良い選択）は **1**（学生には知らせない設定）。
- 各人は **私的シグナル** を受け取る。確率 **70%** で正解を指す（五分よりは賢いが完璧でない）。
- 各人は、前の人たちの **“選択”** は見えるが、その人の私的シグナルは見えない。
- 各人はベイズ的に **合理的に** 判断する。

合理的な判断ルールはこう要約できる ―― **「先行者の選択が一方に2つ以上傾いていたら、自分のシグナル1つでは覆せないので、自分のシグナルを捨てて多数に従う」**。

???+ note "導出①：カスケードをベイズのオッズで書く"

    正解の選択肢を $V$（1 か 0）とする。どちらが正しいか事前には五分五分なので、**事前オッズ**は

    $$\frac{P(V=1)}{P(V=0)}=\frac{0.5}{0.5}=1$$

    各人が受け取る私的シグナル $s$ は、確率 $q=0.7$ で正解を指す。つまり

    $$P(s=1\mid V=1)=q,\qquad P(s=1\mid V=0)=1-q$$

    第3回のオッズ形式のベイズより、事後オッズは事前オッズに**尤度比**を掛けたものになる。

    $$\underbrace{\frac{P(V=1\mid s)}{P(V=0\mid s)}}_{\text{事後オッズ}}=\underbrace{\frac{P(V=1)}{P(V=0)}}_{\text{事前オッズ}}\times\underbrace{\frac{P(s\mid V=1)}{P(s\mid V=0)}}_{\text{尤度比}}$$

    $s=1$ を受け取ったときの尤度比は $q/(1-q)=0.7/0.3=7/3$。事前オッズが 1 なので事後オッズも $7/3>1$ となり、1 を選ぶ。**私的シグナル1つの重みは、尤度比 $7/3$ という1つの数に集約される。** この先の議論は、すべてこの数の掛け算で進む。

    **使った数学**：条件付き確率とベイズの定理（第3回）。オッズと尤度比の掛け算。

???+ note "導出②：なぜ「差が2つ」で覆せなくなるのか"

    先行者の選択も証拠になる。カスケードが始まる前の人は自分のシグナルに従って選ぶので、**その人の選択を見ることは、その人のシグナルを見ることと同じ**である。だから先行者が 0 を選んでいれば、$s=0$ を1つ観測したのと同じ重み、つまり尤度比 $(1-q)/q=3/7$ を掛けることになる。

    いま先行者の選択が 0 のほうに $d$ 人分傾いていて、自分のシグナルは $s=1$ だとする。証拠は独立に集まるので尤度比は掛け算になり、事後オッズは

    $$\left(\frac{1-q}{q}\right)^{d}\times\frac{q}{1-q}=\left(\frac{1-q}{q}\right)^{d-1}$$

    これが 1 より大きければ自分のシグナルが勝ち、小さければ覆せない。$q>1/2$ なら $(1-q)/q<1$ なので、

    $$\left(\frac{1-q}{q}\right)^{d-1}<1 \iff d\ge 2$$

    | 先行者の差 $d$ | 事後オッズ | 自分のシグナルは |
    |---:|---:|---|
    | 0 | 2.33 | 勝つ |
    | 1 | 1.00 | 互角 |
    | 2 | 0.43 | 覆せない |
    | 3 | 0.18 | 覆せない |

    $d=1$ でちょうど互角になるのは偶然ではない。先行者1人ぶんと自分のシグナル1つは、まったく同じ大きさの尤度比を持つからである。**上の節の「2つ以上傾いていたら従う」というルールは、この不等式から出てくる。** $q$ の値にもよらない。$q$ が 0.7 でも 0.9 でも、$q>1/2$ でありさえすれば $d\ge2$ で覆せなくなる。

    **数値で確かめる**：$q=0.7$、先行2人が 0、自分のシグナルが 1 のとき、事後オッズは $(3/7)^2\times(7/3)=3/7$、正解が 1 である確率は $3/10=0.300$。自分のシグナルは 1 を指しているのに、1 である確率のほうが低い。

    **使った数学**：尤度比の掛け算（独立な証拠）、指数の不等式。

## 3. 運の悪い出だしが、全員を道連れにする

正解は1だが、**最初の2人がたまたま外れシグナル(0)** を受け取ったとする。Colabで1人ずつ追うと：

| 順番 | 自分のシグナル | 選択 | 状態 |
|---|---|---|---|
| 1 | 0 | 0 ✗ | 自分のシグナルで判断 |
| 2 | 0 | 0 ✗ | 自分のシグナルで判断 |
| 3 | **1** | 0 ✗ | カスケード（シグナルを無視） |
| 4〜10 | **1** | 0 ✗ | カスケード（シグナルを無視） |

**3人目以降は、自分のシグナルが正解(1)を指しているのに、全員が間違った選択(0)をする。** これは3人目が愚かだからではない。むしろ **合理的だからこそ**「先に2人が0を選んだ。自分のシグナル1つでは覆せない」と正しく計算し、自分の情報を捨てて多数に従った。だが先頭2人の選択は偶然の外れシグナルから生まれたもので、それが後続全員に伝染した。これが **情報カスケード**。

!!! quote "独立が壊れる瞬間"
    カスケードが始まると、3人目以降の選択は **自分の私的情報を反映しなくなる**。みんなが「前の人」という同じ情報源だけを見て動くので、判断が互いに相関し、独立でなくなる。新しい情報が集団に入らなくなるのだ。

???+ note "導出③：カスケードが始まると、情報の流れが止まる"

    $d\ge2$ になった時点で、その人は**自分のシグナルが何であっても同じ選択をする**。導出②の不等式が $s$ の値によらず成り立つからだ。すると、その人の選択を見る次の人にとっては

    $$\frac{P(\text{その人が 0 を選ぶ}\mid V=1)}{P(\text{その人が 0 を選ぶ}\mid V=0)}=\frac{1}{1}=1$$

    となる。$V$ が 1 でも 0 でも、その人は必ず 0 を選ぶからである。**尤度比が 1 とは、証拠として何の重みもないということだ。** 差 $d$ はもう増えない。後続が何人並んでも、公開される情報は先頭の2人分のまま凍りつく。

    ここから2つのことが同時に言える。

    - カスケードに入った人は**合理的に**行動している。導出②の計算は正しく、自分のシグナルより先行者の証拠のほうが重いのは事実である。誰も計算を間違えていない。
    - それでも集団は誤りうる。最初の2人の選択が偶然の外れシグナルから生まれたものなら、その誤りが尤度比として固定され、後続18人の私的情報は**一切集団に入らない**。

    Colabのシミュレーションが、カスケード中に公開情報の差 $m$ を更新しないのは、この「尤度比が 1」をそのまま実装したものである。

    **数値で確かめる**：$q=0.7$、20人で30万回試すと、各自が独立に判断した群衆の多数決は 95.2%、前の人を真似る群れは 84.4% が正解する。一人の賢さはどちらも 70% で同じである。

    **使った数学**：尤度比（第3回）、条件付き確率の計算。

## 4. シミュレーション ―― 群れは、独立な群衆に負ける

シグナルをランダムにして3万回試し、**「前の人を真似る群れ」** と **「各自が自分のシグナルだけで独立に判断する群衆」** で正解率を比べる。どちらも一人の賢さ（シグナル正解率70%）は同じ、20人の集団：

| 集団 | 正解した割合 |
|---|---|
| 各自が独立に判断（群衆） | **約 95%** |
| 前の人を真似る（情報カスケード） | 約 85% |

**一人ひとりの賢さは同じなのに、真似ると約10ポイント落ちる。** 群れが集団的に間違う確率は約16%で、独立な群衆（約5%）の **およそ3倍**。

真似ることで、後から来た18人の **私的情報が集団に入らなくなり**、最初の数人の（時に外れた）判断に全員が引きずられる。**個人は合理的でも、集団は系統的に劣化する。**

現実のカスケード：株や仮想通貨の **バブル**、根拠の薄い **流行**、銀行の **取り付け騒ぎ**、レビュー★の数だけで買う行動、SNSの炎上 ―― どれも「他人が動いた」を見て自分の判断を手放した連鎖だ。
