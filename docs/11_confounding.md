## 1. アイスと水難事故 ―― 共通原因という交絡

「アイスの売上」と「水難事故の件数」は **強く相関する**（Colabで r≈0.78）。アイスを禁止すれば事故は減る？

もちろん違う。両方を引き起こす **共通の原因＝気温** があるからだ。暑い日はアイスも売れるし、水遊びも増えて事故も増える。アイスと事故に直接の因果はない ―― これが **疑似相関（見せかけの相関）**。

```
アイス  ←  気温  →  水難事故
        （共通原因＝交絡）
```

## 2. 統制（調整）―― 気温の影響を差し引く

交絡を見破る基本は **統制（control）**：交絡変数の影響をそろえる／差し引いた上で関係を見る。

Colabでは、アイス売上と水難事故のそれぞれから **気温で説明できる分を回帰で差し引き**、残差どうしの相関＝**偏相関** を見る。

| | 相関係数 |
|---|---|
| 気温を統制する前（全体） | r ≈ +0.78（強い正） |
| 気温を統制した後（偏相関） | **r ≈ −0.02 ← ほぼ0** |

気温の影響を取り除くと、アイスと事故の関係は消える。散布図で見ても、**同じ色（＝同じ気温）の点だけ**を見れば傾きはほとんどない。見えていた相関は気温が作った疑似相関だった。

!!! quote "交絡の構造"
    第10回のRCTは「ランダム化で交絡を断つ」、今回は「交絡を測って統制で断つ」。どちらも交絡を無力化する道だ。違いは、RCTがデータを取る前に断つのに対し、統制は取った後のデータで調整する点。

???+ note "導出①：統制は、何を引き算しているのか（偏相関）"

    3つの変数を $x$＝アイス売上、$y$＝水難事故、$z$＝気温とする。$z$ を統制したときの $x$ と $y$ の**偏相関**は、次の式で書ける。

    $$r_{xy \cdot z} = \frac{r_{xy} - r_{xz} \, r_{yz}}{\sqrt{(1 - r_{xz}^2)(1 - r_{yz}^2)}}$$

    分子を見てほしい。$r_{xz} \, r_{yz}$ は「$x$ と $z$ のつながり」×「$z$ と $y$ のつながり」、つまり **$z$ を経由して説明できる分**である。それを実際の $r_{xy}$ から引いている。残るのは「$z$ では説明できない、$x$ と $y$ の直接の関係」だ。

    分母は、引き算したあとの値を $-1$ から $1$ の範囲に戻すための目盛り直しにあたる。符号を決めているのは分子だけである。

    ここから**疑似相関の見分け方**が式として出てくる。もし $x$ と $y$ のつながりが $z$ 経由だけなら $r_{xy} \approx r_{xz} \, r_{yz}$ となり、分子がほぼ 0、したがって偏相関もほぼ 0 になる。

    **数値で確かめる**：この回のシミュレーションでは $r_{xy} = +0.782$、$r_{xz} = +0.962$、$r_{yz} = +0.817$。積は $0.962 \times 0.817 = +0.786$ で、$r_{xy} = +0.782$ とほぼ等しい。だから分子はほぼ 0 になり、偏相関は $-0.024$ ―― 本文の $\approx -0.02$ である。

    Colab では「それぞれから気温で説明できる分を回帰で引き、残差どうしの相関を取る」という手順で計算した。上の公式で計算しても、どちらも $-0.0235$ で**完全に一致する**。残差を取るという操作と、この分数の引き算は、同じことをしている。

    **使った数学**：相関係数の定義と、2変数の回帰。新しい道具は使っていない。

## 3. シンプソンのパラドックス ―― 結論が真逆になる

交絡はときに、**全体と層別で結論を正反対にする**。これが **シンプソンのパラドックス**。

勉強アプリAとBの合格率（Colabの数値）：

| | アプリA | アプリB | 上なのは |
|---|---|---|---|
| 文系 | 70%（200人） | 75%（80人） | **B** |
| 理系 | 30%（80人） | 35%（200人） | **B** |
| **全体（合算）** | **58.6%** | **46.4%** | **A** ← 逆転！ |

学部別では **両方Bが上** なのに、全体では **Aが上**。なぜか ―― アプリAは受かりやすい **文系** の受験者が多く、アプリBは受かりにくい **理系** が多かった。学部（交絡）の構成比が偏っていたため、合算すると本当の優劣が覆い隠された。

**どちらが正しい？** ―― 学部で統制した（分けて見た）結論、すなわち **Bが上** が正しい。交絡をそろえずに合算した全体の数字に騙されてはいけない。

???+ note "導出②：なぜ逆転が起こりうるのか ―― 分数の足し算の性質"

    分数の不等式として書くと、正体が見える。文系で B が上、理系でも B が上、とは

    $$\frac{a}{b} < \frac{c}{d} \qquad \frac{e}{f} < \frac{g}{h}$$

    が両方成り立つことである（$a/b$ が A の文系合格率、$c/d$ が B の文系合格率、$e/f$ と $g/h$ が理系の同じもの）。ところが合算すると

    $$\frac{a+e}{b+f} > \frac{c+g}{d+h}$$

    となることがある。**分数は、分子どうし分母どうしを足しても順序を保たない。** 理由は、合算した率が単純平均ではなく、**分母の大きさで重みづけした平均**だからである。

    $$\frac{a+e}{b+f} = \frac{b}{b+f} \cdot \frac{a}{b} + \frac{f}{b+f} \cdot \frac{e}{f}$$

    この重み $\dfrac{b}{b+f}$ が A と B で大きく違うと、層ごとの順序が合算でひっくり返る。

    **数値で確かめる**：本文の数値をこの形に入れると、

    $$A : \frac{140 + 24}{200 + 80} = \frac{164}{280} = 0.586 \qquad B : \frac{60 + 70}{80 + 200} = \frac{130}{280} = 0.464$$

    重みを見ると、A は受験者の $200/280 = 71.4\%$ が受かりやすい文系。B は文系が $80/280 = 28.6\%$ しかいない。**A だけが有利な層に重みが寄っている。** 層ごとの合格率では B が上（$70\% < 75\%$、$30\% < 35\%$）なのに全体で A が上に出るのは、合格率の差ではなく、この重みの差が原因である。

    逆にいえば、両アプリで学部の構成比が同じなら逆転は起きない。逆転を起こしているのは **交絡（学部）の構成比の偏り** であって、アプリの実力ではない。

    **使った数学**：分数の加法と加重平均。確率論は使っていない。

## 4. 統制すれば何でも解決？ ―― やりすぎの罠（コライダー）

「手元の変数を全部統制すればいい」も誤りだ。

交絡（共通の原因）は統制すべきだが、**合流点（コライダー：2つの原因が共通して引き起こす結果）を統制すると、逆に存在しない相関を作り出す**。何を統制し、何を統制してはいけないかは、変数どうしの因果の向きを考えないと決められない。

!!! note "だから因果ダイアグラム（DAG）"
    「A→B」の矢印で変数間の因果の向きを描いた図を **DAG** という。これを描くと、どれが交絡（統制すべき）で、どれがコライダー（統制してはいけない）かが見分けられる。統制は機械作業ではなく、因果の仮説に基づく判断だ。

???+ note "導出③：コライダーを統制すると、ない相関が生まれる"

    導出①は「共通の**原因**」を統制する話だった。ここでは「共通の**結果**」を統制するとどうなるかを見る。2つの原因 $x$、$y$ が共通の結果 $c$ を引き起こす構造である。

    ```
    x  →  c  ←  y
        （合流点＝コライダー）
    ```

    例を作ってみる。才能 $x$ と容姿 $y$ は**互いに独立**とし、どちらかが十分高ければ芸能界にデビューできる（$x + y > 1.5$ なら $c = 1$）とする。母集団では $x$ と $y$ に何の関係もない。

    ところが**デビューした人だけ**を見ると、$x + y$ が大きいという条件がついている。すると、才能がさほどでもないのにデビューできた人は、容姿のほうが高いはずだ。逆もまた同じ。**条件をつけたこと自体が、2つの間に負の関係を作り出す。**

    **数値で確かめる**：20万人で試すと、母集団全体では $r = -0.002$（独立なのでほぼ 0）。しかしデビューした人（全体の 14.5%）だけに絞ると $r = -0.686$ になる。**もともと存在しなかった相関が、統制によって作り出された。**

    導出①と見比べてほしい。同じ「統制」という操作が、交絡（共通原因）に対しては**見せかけの相関を消し**、コライダー（共通結果）に対しては**ない相関を作り出す**。しかも $r_{xy \cdot z}$ の計算式は、$z$ が原因なのか結果なのかを**知らないまま実行できてしまう**。式の見た目からは、どちらをやっているか区別がつかない。

    だから、**何を統制すべきかはデータからは決まらない**。変数どうしの因果の向きについての仮定が先にあって、はじめて「これは統制すべき交絡」「これは触ってはいけないコライダー」が決まる。統制は計算ではなく、判断である。

    **使った数学**：条件付き確率（第2回）と相関係数。使ったのは「選抜すると条件付き分布が変わる」という一点だけ。
