## 1. コンドルセの陪審定理 ―― 独立な多数は賢い

設定はシンプル。

- ある問いに正解（YES/NO）がある。
- 一人ひとりはコインより少し賢い ―― 正解率 **55%**。
- 全員が **独立に** 判断し、**多数決** で答えを決める。

**コンドルセの陪審定理**：一人の正解率が 0.5 より高く、各人が独立に判断するなら、**多数決の正解率は、人数を増やすほど 1 に近づく**。

| 人数（独立） | 多数決の正解率 |
|---|---|
| 1 | 55% |
| 51 | 76% |
| 201 | 92% |
| 1001 | **99.9%** |

**たった55%の凡人でも、独立に1000人集めれば多数決はほぼ確実に正解する。** これが「群衆の智慧」の数学的な正体だ。第6回の裏返し ―― 独立な判断は誤りが互いに打ち消し合い、わずかな正解寄りの偏りだけが増幅される。**独立であることが、集団を賢くしている。**

???+ note "導出①：コンドルセの陪審定理はどこから出るのか"

    $n$ 人が同じ問いに答える。各人は確率 $p$ で正解し、判断は互いに**独立**とする。正解した人数を $K$ とすると、$K$ は成功確率 $p$ の試行を $n$ 回くりかえしたときの成功回数、つまり**二項分布**に従う（第4回）。

    $$P(K=k)=\binom{n}{k}p^{k}(1-p)^{n-k}$$

    多数決が正解するのは、正解した人が過半数を超えたときである。したがって

    $$P_n=\sum_{k>n/2}\binom{n}{k}p^{k}(1-p)^{n-k}$$

    ここで $n$ を大きくするとどうなるか。**大数の法則**より、正解者の割合 $K/n$ は $p$ に近づいていく。$p>1/2$ なら $K/n$ は $1/2$ を超えた値に落ち着くので、「過半数」という条件はほぼ必ず満たされる。つまり $P_n\to1$。

    独立性は、二項分布の式を立てるまさにその段階で使っている。各人の正解・不正解を掛け算でつないでよいのは、互いに独立だからである。**定理の主役は人数ではなく、この掛け算を許す独立性のほうだ。**

    !!! note "収束の速さは、この科目の範囲外"
        $K/n$ が $p$ に近づく速さや、$P_n$ が 1 に近づく速さを厳密に評価するには大偏差の評価が要る。ここでは「割合が $p$ に近づくから、$p>1/2$ なら過半数を超え続ける」という筋道までとする。

    **数値で確かめる**：$p=0.55$ として上の式を厳密に計算すると、$n=1$ で 55.00%、$n=51$ で 76.41%、$n=201$ で 92.26%、$n=1001$ で 99.92%。

    **使った数学**：二項分布（第4回）、大数の法則、独立な事象の確率の掛け算。

???+ note "導出②：一人の正解率が半分を下回ると、多数決は確実に誤る"

    導出①の議論は $p$ が $1/2$ より大きいことをどこにも使っていない。使ったのは「$K/n$ が $p$ に近づく」という事実だけである。だから $p<1/2$ のときは、正解者の割合が $1/2$ を下回った値に落ち着き、過半数を超えることがほぼなくなる。つまり $P_n\to0$。

    $p=1/2$ ちょうどなら、$P_n$ は $n$ によらずおよそ $1/2$ のまま。人数を増やしても何も改善しない。

    まとめると、人数 $n$ は**一人ひとりの正しさの向きを増幅する装置**である。向きが正しければ増幅されて 1 へ、誤っていれば増幅されて 0 へ向かう。「多数決だから正しい」のではない。**一人ひとりが半分より正しいことが、定理のもう一つの前提**なのだ。

    **数値で確かめる**：$p=0.45$（半分よりわずかに誤る人たち）で厳密に計算すると、$n=51$ で 23.59%、$n=201$ で 7.74%、$n=1001$ で 0.08%。人数を増やすほど、多数決は確実に誤るほうへ向かう。$p=0.50$ なら $n$ をどれだけ増やしても 50.00% のままである。

    **使った数学**：導出①と同じ。$p$ と $1/2$ の大小だけが結論の向きを決める。

## 2. 「空気を読む」とは、投票を相関させること

空気を読むとは、自分だけの判断ではなく、**その場の雰囲気・多数派の気配に自分の答えを寄せる**こと。モデルでは、全員が共有する「雰囲気」成分の重み $\rho$ を上げることで表せる（$\rho=0$ なら完全に独立、大きいほど同調）。

一人の正解率は **55%のまま**。変えるのは「独立か、空気に従うか」だけ。201人の多数決で $\rho$ を上げると：

| 空気を読む度 $\rho$ | 201人の多数決の正解率 |
|---|---|
| 0（完全に独立） | **約 92%** |
| 0.2（少しだけ空気を読む） | 約 61% |
| 0.5 | 約 58% |
| 0.8 | 約 56% |

**ほんの少し空気を読むだけ（$\rho=0.2$）で、92%が61%まで崩れ落ちる** ―― ほとんど一人の55%に逆戻り。201人という人数の価値が、ほぼ完全に消える。空気を読むと、みんなが同じ「雰囲気」という1つの判断に従うので、実質 **たった1人で決めているのと同じ** になるからだ。

## 3. 人数を増やしても、空気を読む集団は救われない

「人数を増やせば挽回できるのでは？」――独立ならできる。だが空気を読む（相関した）集団では、**いくら人を増やしても正解率は頭打ち**になる。第6回（相関した標本は $n$ を増やしても下げ止まる）とまったく同じ構造だ。Colabのグラフでは、独立な集団（青）だけが人数とともに1へ伸び、空気を読む集団（橙・赤）は5000人集めても賢くならない。

???+ note "導出③：相関が入ると、人数が「実効人数」に縮む"

    ここが今期の到達点である。

    各人の判断を、共有の「雰囲気」成分と個人の成分に分けて書く。Colabのモデルでは

    $$X_i=\sqrt{\rho}\,U+\sqrt{1-\rho}\,Z_i$$

    とする。$U$ は全員が共有する雰囲気、$Z_i$ は各人だけが持つ独立な成分である。この $X_i$ どうしの相関はちょうど $\rho$ になる。$\rho=0$ なら完全に独立、$\rho$ が大きいほど全員が同じ雰囲気に従う。一人の正解率は $\rho$ によらず 55% のまま変わらないことに注意してほしい。**変えているのは賢さではなく、独立性だけである。**

    第6回で導いたように、相関 $\rho$ を持つ $n$ 個の平均の分散は

    $$\mathrm{Var}[\bar{X}]=\frac{\sigma^{2}}{n}\left[1+(n-1)\rho\right]$$

    となる。独立なら $\sigma^{2}/n$ だったものが、$[1+(n-1)\rho]$ 倍に膨らんでいる。

    この分散を、**独立な $n_{\text{eff}}$ 人の平均の分散** $\sigma^{2}/n_{\text{eff}}$ と等しいと置いて $n_{\text{eff}}$ について解くと、

    $$\frac{\sigma^{2}}{n_{\text{eff}}}=\frac{\sigma^{2}}{n}\left[1+(n-1)\rho\right]
    \quad\Longrightarrow\quad
    n_{\text{eff}}=\frac{n}{1+(n-1)\rho}$$

    これが**実効人数**である。$\rho>0$ の集団は、統計的には $n$ 人ではなく $n_{\text{eff}}$ 人分の働きしかしていない。

    $\rho$ を固定したまま $n\to\infty$ とすると、分母では $(n-1)\rho$ が支配的になり、

    $$n_{\text{eff}}\;\longrightarrow\;\frac{1}{\rho}$$

    で**頭打ち**になる。人数をいくら増やしても、実効人数は $1/\rho$ を超えない。$\rho=0.2$ なら、何万人集めても実質5人である。これが「人数を増やしても、空気を読む集団は救われない」ことの正体であり、導出①の $P_n\to1$ が成り立たなくなる理由でもある。定理が間違っているのではない。**前提の独立が消えたので、定理が適用できないのだ。**

    **数値で確かめる**：$\rho=0.2$ のとき、実効人数は 201人で 4.90 人、1001人で 4.98 人、5001人で 5.00 人。頭打ちの $1/\rho=5$ に張り付いている。同じ条件で多数決の正解率をシミュレーションすると、201人で 60.7%、1001人で 61.0%、5001人で 61.5%。人数を25倍にしても 1 ポイントも動かない（シミュレーションなので 0.5 ポイント程度はぶれる）。

    !!! note "実効人数は目安である"
        $n_{\text{eff}}$ は分散をそろえて置き換えた近似であり、多数決の正解率が独立な $n_{\text{eff}}$ 人とぴったり一致するわけではない。実際、$p=0.55$ で独立5人の多数決は 59.3%、$\rho=0.2$ の201人は約 61% で、近いが同じではない。それでも「201人が実質5人分に縮む」という桁の感覚は、この式が正しく与えている。

    **使った数学**：分散の加法性と共分散（第6回）、等式を $n_{\text{eff}}$ について解く、極限。

!!! quote "今期の結論 ―― これは事実である"
    集団が賢くなる条件は「人数が多いこと」ではない。**一人ひとりが独立に判断すること**だ。空気を読む・忖度する・多数派に合わせるという行為は、その独立性を自分から手放すこと ―― いわば **集合知の自殺** である。これは精神論でも価値観でもなく、コンドルセの陪審定理が示す数学的な帰結だ。多数が同じ意見でも、それが互いに空気を読んだ結果なら、その一致にはほとんど情報がない。

## 4. 集団浅慮（グループシンク）と、独立を守る仕組み

独立が失われた集団が、自信満々に間違った結論へ進む現象を、社会心理学では **集団浅慮（groupthink）** と呼ぶ。歴史上の組織的失敗の多くがこれで説明される。だからこそ賢い組織は **独立性を制度で守る**：

- 偉い人から先に意見を言わない（さもないと全員がその「空気」に従う＝$\rho$ が上がる）
- まず各自が **無記名で同時に** 書いて出す（投票・ブレインライティング）
- わざと反対役（悪魔の代弁者）を置く
- 多様な背景の人を入れる（同じ空気を共有させない）

どれも狙いは一つ ―― **判断の独立を守り、$\rho$ を下げること**だ。
