|---|---|

!!! warning "第1回で強調した言い方を、もう一度"
    「独立でないとお手上げ」ではない。正確には
    **「独立を仮定した計算を、依存のあるデータにそのまま当てると危ない」**である。

    コンドルセの陪審定理についても同じだった。あの定理は
    「各人が同じ確率 $p>1/2$ で正答し、その正誤が**互いに独立**なら」という**条件つき**の命題で、
    $p<1/2$ なら人数を増やすほど逆に悪くなる。独立が崩れたときに何が起きるかも
    **依存の仕組みによる**（第12〜13回で検討する）。

中身は分かっていて、**選ぶ記号だけが逆**になっていた。

| 起きた間違い | 何人 | どこが問題か |
|---|---|---|

| 「3条件を満たさないので使えない」で止まり、**「何が分かれば判断できるか」を書かなかった** | 20名 | 設問が明示的に求めていた |

!!! danger "とくに注意してほしい2つの勘違い"
    **(1) 「同調圧力」を、多数決がうまく働く前提として挙げた答案があった。**
    これは**正反対**である。コンドルセの定理が要求するのは「各人の判断が**互いに独立**であること」で、
    同調圧力はその独立性を壊す側の力である。前提そのものを逆向きに覚えてしまっている。

    **(2) 「各人の意見が同じ方向に傾く（＝正答確率が1/2を上回る）」と書いた答案があった。**
    これは **「同調」と「正答確率」を1つにまとめてしまった**ものである。
    意見がそろうことと、一人ひとりが当てやすいことは、**別の量**である。
    全員が同じ間違いに傾けば、意見はそろっても正答率は下がる。

    どちらも「**独立という言葉を、まだ日常語のまま使っている**」ことから来ている。
    第1回では独立を定義せずに名前だけ出したので、無理のない混乱でもある。

!!! tip "今日の定義で、この2つは切り分けられる"
    今日 $P(A\mid B)=P(A)$ という式で独立を定義すると、上の2つはこう整理できる。

    - **同調**は「他人の判断 $B$ を知ると自分の判断 $A$ の確率が変わる」こと、つまり $P(A\mid B)\neq P(A)$ ―― **従属**である
    - **正答確率** $p$ は、一人の判断が正解と一致する確率そのもの。$P(A\mid B)$ と $P(A)$ の**関係**とは別の話

    言葉のままだと混ざるものが、式にすると**別の場所に書かれる**。それが定義をする理由である。

!!! note "A1の「向き」の間違いも、今日の話につながる"
    「平均 ＞ 中央値」か「中央値 ＞ 平均」か ―― これは**向き**の間違いだった。
    今日定義する条件付き確率でも、$P(A\mid B)$ と $P(B\mid A)$ という**向き**が最大の落とし穴になる
    （第3回では、これが医療検査の読み違いとして現れる）。
    内容が分かっていても向きで落とす、というのは統計でくり返し起きる。

## 1. 直感クイズ ―― 2人の子ども問題

ある家庭に子どもが **2人** いる（男女は半々で独立に決まるとする）。
いま **「少なくとも1人は女の子」** だと分かっている。

**問い：2人とも女の子である確率は？**

直感の多くは「もう1人が女か男か、だから 1/2」と答える。だが正解は **1/3** である（下のシミュレーションでは約0.333）。

理由は、もともとの組み合わせが等確率で4通りあること。

| 上の子 | 下の子 | 「少なくとも1人女」を満たすか |
|---|---|---|
| 男 | 男 | ✗（消える） |
| 男 | 女 | ✓ |
| 女 | 男 | ✓ |
| 女 | 女 | ✓（これが「2人とも女」） |

「少なくとも1人は女」という情報で **(男,男) が消える**。残った3通りのうち「2人とも女」は1通り。だから **1/3**。情報を得た瞬間、確率が $1/4 \to 1/3$ に **更新** された。

!!! tip "Colabで確認"
    `02_conditional.ipynb` で10万世帯をシミュレーション → `P(2人とも女 | 少なくとも1人女) ≈ 0.333`。直感の 0.5 は出てこない。

## 2. 条件付き確率とは

事象 $B$ が起きたと分かったうえでの $A$ の確率を **条件付き確率** と呼び、こう書く。

$$P(A\mid B) = \frac{P(A \cap B)}{P(B)} \qquad (P(B)>0)$$

!!! note "式の読み方"
    まず、声に出して読んでみる。

    > 「**ビー** のもとでの **エー** の確率は、**エーかつビー** の確率を **ビー** の確率で割ったもの」

    記号を1つずつ分解すると、こうなる。

    | 記号 | 読み | 何を指しているか |
    |---|---|---|
    | $P(\;\cdot\;)$ | 「…の確率」 | |
    | $A \cap B$ | 「$A$ **かつ** $B$」 | $A$ と $B$ が**両方**起きた場合 |
    | $A \mid B$ | 「$B$ **のもとでの** $A$」 | 縦棒の右が**条件**、左が**知りたいこと** |
    | 分子 $P(A\cap B)$ | | 絞り込んだ舞台の中で、$A$ も起きている部分 |
    | 分母 $P(B)$ | | 絞り込んだ**あとの舞台ぜんたい** |

    **読む順番のコツ：縦棒を見たら、右から読む。** $P(A\mid B)$ を左から「エー、ビー」と読むと
    向きを取り違えやすい。先に右の $B$ を見て「舞台は $B$ に限る」と決め、それから左の $A$ を読む。
    英語では "the probability of $A$ **given** $B$"（$B$ が与えられたときの $A$ の確率）と読み、
    この語順のほうが条件が後ろに来る。

!!! warning "よくある読み間違い"
    | 読み間違い | 実際にはどの式か |
    |---|---|
    | 「$A$ と $B$ の確率」 | それは $P(A\cap B)$。条件付き確率は**割り算が入る**ので別物 |
    | 「$A$ が起きてから $B$ が起きる確率」 | 時間の順番ではない。しかも向きが逆 |
    | 「$A$ または $B$ の確率」 | それは $P(A\cup B)$。$\cap$ と $\cup$ は別の記号 |

    書くときの注意：$P(A\mid B)$ の縦棒は **割り算の記号ではない**。$P(A/B)$ とは書かない。
    割り算は式の右辺にあって、縦棒そのものは「条件がついている」という印である。

    縦棒の右側は**条件**であって、**先に起きた出来事という意味ではない**。
    時間の前後とは関係がなく、$P(B\mid A)$ のように向きを逆にすることもできる（第3回のベイズはまさにこれ）。

意味は「$B$ という条件の世界に絞り込み、その中で $A$ が占める割合」。Colabのコード `両方女[少なくとも1人女].mean()` は、まさに **「条件を満たす世帯だけに絞って、その中の割合を測る」** 操作だった。

> **情報を得る ＝ 標本空間を絞り込む ＝ 確率を更新する。** この考え方は第3回のベイズの定理にそのまま続く。

???+ note "導出①：なぜ分母が $P(B)$ なのか"

    この定義は天下りに見えるが、やっていることは **割合の測り直し** である。

    全体を面積 1 の四角形だと思う。$B$ が起きたと分かった時点で、舞台は $B$ の内側だけに狭まる。$B$ の外側は起こらなかったのだから、もう数えない。

    狭まった舞台の広さは $P(B)$。その中で $A$ も起きている部分の広さは $P(A\cap B)$。だから「新しい舞台の中で $A$ が占める割合」は

    $$P(A\mid B) = \frac{P(A\cap B)}{P(B)}$$

    分母が $P(B)$ なのは、**舞台を $B$ に狭めたぶん、全体がふたたび 1 になるように測り直している**からである。確かめてみると $P(B\mid B)=P(B)/P(B)=1$ になる。狭めた舞台の中では、$B$ はもう必ず起きている。

    場合の数で言えば「$B$ を満たす場合だけを分母に数え直す」こと。Colab の `両方女[少なくとも1人女].mean()` は、この絞り込みをそのまま実行している。

    **使った数学**：割合の定義と、比の測り直し（算数）。確率の難しい性質は何も使っていない。

???+ note "導出②：2人の子ども問題を、定義に当てはめて解く"

    $A$＝「2人とも女」、$B$＝「少なくとも1人は女」とおく。男女が半々で独立に決まるので、(上の子, 下の子) の4通りはどれも確率 $1/4$ である。

    - $B$ を満たすのは (男,女)、(女,男)、(女,女) の3通り。よって $P(B)=3/4$。
    - $A$ が起きていれば $B$ も自動的に起きるので $A\cap B$ は (女,女) の1通りだけ。よって $P(A\cap B)=1/4$。

    導出①の式に入れる。

    $$P(A\mid B) = \frac{P(A\cap B)}{P(B)} = \frac{1/4}{3/4} = \frac{1}{3}$$

    直感が $1/2$ と答えてしまうのは、分母を $P(B)=3/4$ ではなく「もう1人の性別が2通り」だと思うからである。**条件をつけた瞬間に、舞台が4通りから3通りへ変わる**。情報が消したのは (男,男) の1通りだけで、残った3通りは等確率のままだから、分母は 2 ではなく 3 になる。

    事前は $P(A)=1/4$、事後は $P(A\mid B)=1/3$。情報を得て確率が更新された。

    **使った数学**：場合の数と分数の割り算（算数）。

## 3. 今期の主役 ―― 「独立」

ここで、統計学Ⅱでもっとも重要な概念を定義する。

事象 $A$ と $B$ が **独立** であるとは ―― **$B$ を知っても $A$ の確率が変わらない** こと。

$$P(A\mid B) = P(A) \qquad\Longleftrightarrow\qquad P(A\cap B)=P(A)\,P(B)$$

逆に、$B$ を知ると $A$ の確率が変わるなら、2つは **従属（独立でない）** という。

| | 例 | $P(A)$ | $P(A\mid B)$ | 判定 |
|---|---|---|---|---|
| 独立 | コインを2回投げる（A=2投目表, B=1投目表） | $1/2=0.500$ | $1/2=0.500$ | 変わらない → **独立** |
| 従属 | トランプを戻さず2枚引く（A=2枚目♥, B=1枚目♥） | $13/52=0.250$ | $12/51\approx0.235$ | 下がる → **従属** |

「1投目が表でも2投目の確率は変わらない」。一方「1枚目にハートを引くと、山札のハートが減るので2枚目の確率は下がる」。**この差が独立かどうかの分かれ目**だ。

!!! question "「2枚目なのに、分母が52なのはなぜ？」"
    $P(A)=13/52$ の $A$ は「**2枚目**がハート」である。

    **1枚目が何だったか知らない段階**では、よく混ぜた山札の2番目の位置にハートが来る確率は、
    1番目の位置と同じく $13/52$ である。どの位置も対等だからだ。

    ところが **1枚目がハートだと分かった**なら、残りは51枚でハートは12枚なので $12/51\approx0.235$。
    **情報を得たから分母と分子が切り替わった** ―― これが条件付き確率である。

!!! warning "シミュレーションの数字は、理論値とぴたりとは一致しない"
    Colabで同じことを乱数で確かめると、独立なコインの例でも
    $\widehat{P}(A)=0.500350$、$\widehat{P}(A\mid B)=0.498873$ のように**わずかにずれる**。

    これは**有限回しか試していないことによるばらつき**であって、独立でない証拠ではない。
    逆に「近い数字が出たから独立だと**証明された**」とも言えない。
    このシミュレーションは、**2回のコイン投げが独立だというモデル**のもとで動かしている。
    **有限回の実測割合が一致するかどうかで、独立性を判定しているのではない。**

???+ note "導出③：独立の2つの表現は、同じことを言っている"

    独立は2通りに書かれる。この2つが同値であることは、導出①の定義を代入するだけで分かる（以下 $P(B)>0$ とする）。

    **左から右へ**：$P(A\mid B)=P(A)$ の両辺に $P(B)$ を掛ける。左辺は定義より $P(A\cap B)/P(B)$ だったから、

    $$P(A\cap B) = P(A\mid B)\,P(B) = P(A)\,P(B)$$

    **右から左へ**：$P(A\cap B)=P(A)P(B)$ の両辺を $P(B)$ で割る。左辺は定義より $P(A\mid B)$ だから、

    $$P(A\mid B) = \frac{P(A)\,P(B)}{P(B)} = P(A)$$

    掛けるか割るかの一手で、どちらの向きにも移り合う。**新しい仮定は何も足していない。**

    !!! note "積の形は対称である"
        $P(A\cap B)=P(A)P(B)$ は、$A$ と $B$ を入れ替えても同じ式になる。**独立は一方通行の関係ではなく、対等な関係**である。さらに $P(A)>0$ なら、逆向きにも $P(B\mid A)=P(B)$ と書ける（割る相手が $P(A)$ になるので、こちらが正であることが要る）。$P(A\mid B)=P(A)$ の形では $B$ だけが特別な役に見えるが、積の形に直すとその対称性がはっきりする。

    この **積の形** が、今期ずっと使われる。第4回の二項分布は「独立だから確率を掛けてよい」で組み立てられ、第6回の標本平均のばらつきも第7回の標準誤差も、もとをたどればこの掛け算から出てくる。第12〜13回で独立が壊れるとき、壊れるのはこの式である。**今日のこの1行が、今期の残り全部を支えている。**

    **使った数学**：定義の代入と、両辺への掛け算・割り算（算数）。

## 3.5 もうひとつ計算してみる ―― $A$ と $B$ が重なりきらない例

子ども問題は $A$（2人とも女）が起きれば必ず $B$（少なくとも1人女）も起きるので、$P(A\cap B)=P(A)$ になっていた。
**いつもそうなるわけではない。**$A$ だけ・$B$ だけ・両方、の3通りがある例で確かめる。

> 学生100人を調べたところ、**アルバイトをしている人が30人**、**一人暮らしの人が20人**、
> **その両方に当てはまる人が12人**だった。この100人から1人を等確率で選ぶ。
> $A$＝「アルバイトをしている」、$B$＝「一人暮らしである」とする。

$$P(A)=\frac{30}{100}=0.30,\qquad P(B)=\frac{20}{100}=0.20,\qquad P(A\cap B)=\frac{12}{100}=0.12$$

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}=\frac{12/100}{20/100}=\frac{12}{20}=0.60$$

**分母が100人から20人に切り替わり、分子が30人から12人に切り替わった。**これが「条件の世界に絞り込む」ということである。

向きを逆にすると値が変わることも確かめておく。

$$P(B\mid A)=\frac{12/100}{30/100}=\frac{12}{30}=0.40$$

$P(A\mid B)=0.60$ と $P(B\mid A)=0.40$ は**別の量**である。縦棒のどちら側が条件かで答えが変わる。

そして $P(A)=0.30$ に対して $P(A\mid B)=0.60$ なので、**この100人の中では $A$ と $B$ は独立ではない**。
（積の形でも確かめられる：$P(A)P(B)=0.30\times0.20=0.06 \neq 0.12=P(A\cap B)$）

## 4. なぜ「独立」が今期の主役なのか

この授業で扱う道具は、**独立を仮定した基本形**から入る。

- 第4回 **二項分布** … 独立な試行を $n$ 回くりかえす
- 第5回 **正規分布** … 独立な多数の要因が足し合わさる場合の近似
- 第6回 **中心極限定理** … 独立な標本の平均
- 第7回 **区間推定** … 独立な標本を仮定して誤差の幅を計算する

そして第12〜13回で、人々が **「空気を読んで」** 互いの判断を真似し始めると、この **独立の仮定が成り立たなくなり**、
**独立を前提に導いた多数決の保証がそのままでは使えなくなる**ことを見る。

!!! warning "「独立でなければ統計が使えない」ではない"
    独立は**便利な仮定**であって、統計の必要条件ではない。
    依存関係がある場合でも、**その依存をモデルに組み込めば**推定はできる（時系列、階層モデル、クラスター標本など）。

    この授業が独立から始めるのは、**式がいちばん簡単になるから**である。
    気をつけるべきなのは、**独立でないデータに、独立を仮定した公式をそのまま当てはめること**のほうだ。

    なお、**正規分布に従うこと**と**複数の観測が独立であること**は別の話である。
    正規分布は1つの変数の分布の形、独立は複数の変数の関係であって、どちらか一方だけが成り立つこともある。

!!! quote "独立とは"
    **一方が起きたと知っても、もう一方の確率が変わらない**という、確率どうしの関係である。

    「互いに影響し合わない」という**因果の話ではない**。
    たとえば2人の学生が連絡を取り合っていなくても、同じ路線の運休で2人とも欠席するなら、
    「Aが欠席した」と知ることで「Bも欠席している」確率は上がる。**$A$ と $B$ の間に直接の因果関係がなくても、共通の原因によって従属になることがある。**

    今日その定義を手に入れた ―― これが第13回「コンドルセの陪審定理」への伏線になる。

## 5. 注意 ―― 「独立」と「排反」は別物

よくある混同。サイコロで $A$＝「偶数の目」、$B$＝「3の目」とする。

- $A$ と $B$ は **排反**（同時には起きない。3は偶数ではない）
- だが **独立ではない**：$B$（3が出た）と分かれば $A$（偶数）の確率は $1/2 \to 0$ に変わる

**排反は「重ならない」、独立は「知っても確率が変わらない」。** まったく別の概念。Colabでも `P(偶数 | 3が出た) = 0.000` となり、条件で確率が激変する＝独立でないことが確認できる。

## 今日のまとめ

| 概念 | 意味 | 式 |
|---|---|---|
| 条件付き確率 | $B$ を知った後の $A$ の確率。情報で更新 | $P(A\mid B)=\dfrac{P(A\cap B)}{P(B)}$ |
| 独立 | $B$ を知っても $A$ の確率が変わらない | $P(A\mid B)=P(A)$ |
| 排反 | $A$ と $B$ は同時に起きない（≠独立） | $P(A\cap B)=0$ |
