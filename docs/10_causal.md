## この回のゴール

- 因果が **反事実**（同じ人の「した世界 vs しない世界」）の比較であることを理解する
- **交絡** が観察データで見せかけの効果を作ることを見抜く
- **RCT（ランダム化比較試験）** がなぜ因果を示せるか＝ランダム化が処置を交絡から **独立** にするから、を説明できる
- 観察研究の限界（交絡・選択バイアス）を理解する
- **発展**：平均因果効果 $E[Y(1)]-E[Y(0)]$ を定義し、ランダム化がそれを $E[Y\mid T=1]-E[Y\mid T=0]$ と一致させることを、自分で導ける

到達目標との対応：**G3（因果推論の基礎を理解し、観察データからの安易な因果主張を見抜ける）** の出発点。

## 1. 直感クイズ ―― サプリは効いたのか？

あるサプリの利用者を調べたら、**飲んでいる人のほうが健康だった**。これは「サプリが健康にする」という因果の証拠か？

なりそうに見える。だが ―― サプリを自分から飲む人は、そもそも **健康志向が高い**（運動する・食事に気をつける）人が多いのでは？ だとすれば、健康なのはサプリのおかげではなく、**もともとそういう人が飲んでいるだけ** かもしれない。

この「健康志向」のように、**原因の候補と結果の両方に影響する隠れた要因**を **交絡（confounder）** と呼ぶ。

---

## 2. 因果とは「反事実」の比較

「サプリが効いた」とは本当はこういう意味だ：

> 同じ人が、サプリを飲んだ世界と、飲まなかった世界を比べて、健康に差がある。

だが現実には、1人について「飲んだ場合」と「飲まなかった場合」の両方は観測できない（**反事実**）。だから「飲んだ人の集団」と「飲まなかった人の集団」を比べる。このとき2つの集団が **健康志向などでそろっていない** と、比較は因果ではなく交絡を映す。

???+ note "導出①：因果効果を式で書く ―― 観測できない量を定義する"

    1人の個体 $i$ について、2つの世界を考える。

    - $Y_i(1)$：処置を受けた世界（サプリを飲んだ）での結果
    - $Y_i(0)$：受けなかった世界での結果

    個体 $i$ の因果効果は、この2つの差である。

    $$\tau_i = Y_i(1) - Y_i(0)$$

    集団全体で平均したものを**平均因果効果**という。

    $$\tau = E[Y(1) - Y(0)] = E[Y(1)] - E[Y(0)]$$

    ところが、実際に観測できるのは片方だけだ。処置の有無を $T_i$（飲んだら 1、飲まなければ 0）と書くと、観測される結果は

    $$Y_i = T_i \, Y_i(1) + (1 - T_i) \, Y_i(0)$$

    $T_i=1$ の人からは $Y_i(1)$ しか見えず、$Y_i(0)$ は永久に分からない。$T_i=0$ ならその逆。つまり **$\tau_i$ は、どの個体についても計算できない**。これを因果推論の根本問題という。

    上の「同じ人の、した世界と、しない世界を比べる」という言葉が、そのまま $Y_i(1) - Y_i(0)$ という式になっている。そして式に書いた瞬間に、それが観測できないことも見えてしまう。だから因果推論は、**観測できない量を、観測できる量からどう言い当てるか**という問題になる。

    **使った数学**：記号の定義と場合分けのみ。確率も微分も使っていない。

## 3. シミュレーション：交絡が「効果」を捏造する

架空の世界 ―― **サプリの本当の効果はゼロ**。健康を決めるのは「健康志向」だけ。健康志向が高い人ほど自分からサプリを飲む。この世界で「飲んだ人 vs 飲まない人」を比べると：

| | 値 |
|---|---|
| サプリの本当の効果 | 0 |
| 観察データの「飲んだ人 − 飲まない人」の健康差 | **+9.4** |

**効果ゼロのはずなのに、飲んだ人のほうがずっと健康に見える。** 差の正体は、飲む人と飲まない人で **健康志向が偏っている**こと（飲んだ群 +0.58 / 飲まない群 −0.61）。

観察研究では「飲むかどうか」を本人が決めるので、**処置（飲む）と交絡（健康志向）が独立でない**。第6回からの言葉そのものだ。

---

## 4. RCT ―― ランダム化が交絡を断ち切る

本当の効果を知るには、**くじ引きで誰がサプリを飲むかを決める**。これが **RCT**。本人の健康志向と無関係に割り当てるので、2群の健康志向が平均的にそろう。

| | 飲んだ群の健康志向 | 飲まない群 | 推定された効果 |
|---|---|---|---|
| 観察研究（本人が選ぶ） | +0.58 | −0.61 | +9.4（捏造） |
| RCT（くじで割当） | ≈0.00 | ≈−0.06 | **+0.5（≈真の効果0）** |

ランダム化の威力は **「処置」を「交絡」から独立にする**こと。くじ引きは健康志向を見ないので、群間の差は純粋にサプリの効果だけを映す。これがRCTが「因果推論の金字塔」と呼ばれる理由だ。

!!! quote "今期の糸がここでも"
    第6〜7回は「独立が崩れると推測が壊れる」だった。因果推論はその逆を積極的に使う ―― **ランダム化で“処置と交絡の独立”を人工的に作り出す**ことで因果を取り出す。独立は、壊れると困るだけでなく、自分で作り出せれば強力な武器になる。

???+ note "導出②：ランダム化はなぜ効くのか ―― 独立性を「作る」"

    観測できるのは、次の2つの平均だけである。

    $$E[Y \mid T=1] \qquad E[Y \mid T=0]$$

    導出①の定義より、$T=1$ の人では $Y = Y(1)$、$T=0$ の人では $Y = Y(0)$ なので、

    $$E[Y \mid T=1] - E[Y \mid T=0] = E[Y(1) \mid T=1] - E[Y(0) \mid T=0]$$

    ここまでは、ただの書き換えである。ほしいのは $E[Y(1)] - E[Y(0)]$ なのに、右辺には条件 $\mid T=1$、$\mid T=0$ がついたままだ。「飲んだ人の中での $Y(1)$ の平均」は、「全員の $Y(1)$ の平均」とは限らない。

    ここでくじ引きの出番になる。$T$ をくじで決めると、$T$ は潜在結果 $(Y(0), Y(1))$ と **独立**になる。独立なら条件をつけても平均は変わらないので、

    $$E[Y(1) \mid T=1] = E[Y(1)] \qquad E[Y(0) \mid T=0] = E[Y(0)]$$

    **独立を使ったのは、この1行だけである。** ここだけが、くじで決めたという事実を必要としている。これを代入すると、

    $$E[Y \mid T=1] - E[Y \mid T=0] = E[Y(1)] - E[Y(0)] = \tau$$

    左辺は観測できる。右辺は観測できないはずの平均因果効果である。RCTが因果を示せるのは、この1行のためだ。

    **数値で確かめる**：この回のシミュレーション（真の効果は 0）では、RCTの群間差は **+0.52**。くじで割り当てた2群の健康志向は **−0.00 と −0.06** でそろっている。

    !!! warning "独立は「確かめる」ものではなく「作る」もの"
        上の代入が許されるのは、$T$ を**くじで決めたと分かっているから**である。手元のデータを眺めて「2群が似ているから独立だろう」と判断することはできない。似て見えても、**測っていない**交絡までそろっている保証はどこにもないからだ。

        独立性は、データを取る**前**の設計（ランダム化）によって作られる。式の条件を満たしているかどうかは、データの中身ではなく、**どうやってそのデータを取ったか**で決まる。ここを取り違えると、「表を見比べたら似ていたので因果と言える」という誤りに落ちる。

    **使った数学**：条件付き期待値の定義と、独立なら条件付き期待値が元の期待値に等しいこと（第2回）。

???+ note "導出③：ランダム化しないと何が残るか ―― バイアスの正体"

    くじを使わない場合、導出②の独立性は成り立たない。それでも書き換えだけは進められる。$E[Y(0) \mid T=1]$（**飲んだ人が、もし飲まなかったら**どうだったか）を足して引くと、

    $$E[Y \mid T=1] - E[Y \mid T=0] = \Big( E[Y(1) \mid T=1] - E[Y(0) \mid T=1] \Big) + \Big( E[Y(0) \mid T=1] - E[Y(0) \mid T=0] \Big)$$

    第1項は「飲んだ人における因果効果」。第2項が **選択バイアス**である。第2項をよく見ると、どちらも $Y(0)$ ―― つまり**誰も飲まなかった世界**での結果だ。処置と関係なく、飲む人と飲まない人がもともとどれだけ違っていたかを表している。

    $T$ が潜在結果と独立なら第2項は 0 になり、導出②に戻る。独立でなければ、観測される差は因果効果に選択バイアスが上乗せされたものになる。

    **数値で確かめる**：第3節の世界では、健康は $50 + 8 \times (健康志向) + 誤差$ で決まり、サプリの効果は 0 だった。飲んだ群と飲まない群の健康志向の差は $0.58 - (-0.61) = 1.19$ なので、選択バイアスは $8 \times 1.19 = +9.5$。観察データの差 **+9.4** とほぼ一致する（残りのずれは誤差項のばらつき）。

    効果が 0 なのに差が出たのではない。**差の全部がバイアスだった**のである。第3節のシミュレーションは、この式の第2項を数値で見せたものだ。

    **使った数学**：期待値の線形性（同じ量を足して引く）。第2回の条件付き期待値。

## 5. 観察研究はダメなのか ―― いや、注意して使う

現実にはRCTができない場面も多い（「20年間タバコを吸う/吸わない」をくじで割り当てるのは不可能・非倫理的）。その場合は観察研究に頼るが、**交絡を疑い、できる限り調整する**必要がある（→第11回）。

もう一つの罠が **選択バイアス**（対象の集め方が偏ると何を比べても歪む）。RCTの **盲検・プラセボ**（偽薬）は、「飲んでいる」という意識自体の影響を消す工夫だ。

!!! note "因果を見抜く問い"
    「Xをした人はYだった」と聞いたら問う ―― **「Xをした人としなかった人は、他の点でそろっている？」「くじで決めた？ それとも本人が選んだ？」**。本人が選んだなら、その差は交絡かもしれない。

## 今日のまとめ

| ポイント | 中身 |
|---|---|
| 因果 | 反事実（同じ人の“した世界 vs しない世界”）の比較。本来は観測できない |
| 交絡 | 原因候補と結果の両方に影響する隠れ要因。観察研究で効果を捏造する |
| RCT | くじ引きで処置を割当→処置と交絡が**独立**に→真の効果が出る |
| 観察研究 | RCTが無理なときに使うが、交絡・選択バイアスを疑い調整が必要 |
