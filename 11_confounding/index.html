    第11回　交絡と疑似相関¶

    見せかけの相関を、統制（調整）で見破る

    考え方をガイドで確かめる

    この回の考え方は、統計の考え方ガイドの「相関と因果」でも解説しています。霊長類のデータを動かしながら確かめられます。

    この回のゴール¶

    • 疑似相関（共通原因が作る見せかけの相関）を理解する
    • 統制（調整） で交絡の影響を取り除けることを、偏相関で確かめる
    • シンプソンのパラドックス（全体と層別で結論が逆転）を体験する
    • 「何でも統制すればよい」わけではない（コライダーの罠）ことを知る
    • 発展：偏相関の式が「\(z\) 経由で説明できる分を引いたもの」だと読め、シンプソンの逆転が加重平均で起きることを、自分で導ける

    到達目標との対応：G3（交絡・疑似相関を理解し、観察データからの安易な因果主張を見抜ける） の本丸。

    1. アイスと水難事故 ―― 共通原因という交絡¶

    「アイスの売上」と「水難事故の件数」は 強く相関する（Colabで r≈0.78）。アイスを禁止すれば事故は減る？

    もちろん違う。両方を引き起こす 共通の原因＝気温 があるからだ。暑い日はアイスも売れるし、水遊びも増えて事故も増える。アイスと事故に直接の因果はない ―― これが 疑似相関（見せかけの相関）。

    アイス  ←  気温  →  水難事故
        （共通原因＝交絡）

    「交絡」という言葉の出どころ

    この語を統計に持ち込んだのは ロナルド・フィッシャー である。1920年代、イギリスのロザムステッド農事試験場で肥料の効き目を比べていた彼は、試験場ごとの成績の差が天候の違いで大きく動き、肥料そのものの差は小さいことに気づいた。肥料の効果と天候の効果が、区別できない形で混ざっている ―― これを confounded（交絡している） と書いた。

    つまり交絡はもともと「2つの原因が分離できない」という、実験計画の言葉である。「見せかけの相関」という言い方より、こちらのほうが本質に近い。 そしてフィッシャーが1935年の『実験計画法』で ランダム化 を打ち出したのは、この分離できなさを、データを取る前に断つためだった。第10回のRCTは、ここから来ている。

    2. 統制（調整）―― 気温の影響を差し引く¶

    交絡を見破る基本は 統制（control）：交絡変数の影響をそろえる／差し引いた上で関係を見る。

    Colabでは、アイス売上と水難事故のそれぞれから 気温で説明できる分を回帰で差し引き、残差どうしの相関＝偏相関 を見る。

    相関係数
    気温を統制する前（全体） r ≈ +0.78（強い正）
    気温を統制した後（偏相関） r ≈ −0.02 ← ほぼ0

    気温の影響を取り除くと、アイスと事故の関係は消える。散布図で見ても、同じ色（＝同じ気温）の点だけを見れば傾きはほとんどない。見えていた相関は気温が作った疑似相関だった。

    交絡の構造

    第10回のRCTは「ランダム化で交絡を断つ」、今回は「交絡を測って統制で断つ」。どちらも交絡を無力化する道だ。違いは、RCTがデータを取る前に断つのに対し、統制は取った後のデータで調整する点。

    導出①：統制は、何を引き算しているのか（偏相関）

    3つの変数を \(x\)＝アイス売上、\(y\)＝水難事故、\(z\)＝気温とする。\(z\) を統制したときの \(x\) と \(y\) の偏相関は、次の式で書ける。

    \[r_{xy \cdot z} = \frac{r_{xy} - r_{xz} \, r_{yz}}{\sqrt{(1 - r_{xz}^2)(1 - r_{yz}^2)}}\]

    分子を見てほしい。\(r_{xz} \, r_{yz}\) は「\(x\) と \(z\) のつながり」×「\(z\) と \(y\) のつながり」、つまり \(z\) を経由して説明できる分である。それを実際の \(r_{xy}\) から引いている。残るのは「\(z\) では説明できない、\(x\) と \(y\) の直接の関係」だ。

    分母は、引き算したあとの値を \(-1\) から \(1\) の範囲に戻すための目盛り直しにあたる。符号を決めているのは分子だけである。

    ここから疑似相関の見分け方が式として出てくる。もし \(x\) と \(y\) のつながりが \(z\) 経由だけなら \(r_{xy} \approx r_{xz} \, r_{yz}\) となり、分子がほぼ 0、したがって偏相関もほぼ 0 になる。

    数値で確かめる：この回のシミュレーションでは \(r_{xy} = +0.782\)、\(r_{xz} = +0.962\)、\(r_{yz} = +0.817\)。積は \(0.962 \times 0.817 = +0.786\) で、\(r_{xy} = +0.782\) とほぼ等しい。だから分子はほぼ 0 になり、偏相関は \(-0.024\) ―― 本文の \(\approx -0.02\) である。

    Colab では「それぞれから気温で説明できる分を回帰で引き、残差どうしの相関を取る」という手順で計算した。上の公式で計算しても、どちらも \(-0.0235\) で完全に一致する。残差を取るという操作と、この分数の引き算は、同じことをしている。

    使った数学：相関係数の定義と、2変数の回帰。新しい道具は使っていない。

    3. シンプソンのパラドックス ―― 結論が真逆になる¶

    交絡はときに、全体と層別で結論を正反対にする。これが シンプソンのパラドックス。

    勉強アプリAとBの合格率（Colabの数値）：

    アプリA アプリB 上なのは
    文系 70%（200人） 75%（80人） B
    理系 30%（80人） 35%（200人） B
    全体（合算） 58.6% 46.4% A ← 逆転！

    学部別では 両方Bが上 なのに、全体では Aが上。なぜか ―― アプリAは受かりやすい 文系 の受験者が多く、アプリBは受かりにくい 理系 が多かった。学部（交絡）の構成比が偏っていたため、合算すると本当の優劣が覆い隠された。

    どちらが正しい？ ―― 学部で統制した（分けて見た）結論、すなわち Bが上 が正しい。交絡をそろえずに合算した全体の数字に騙されてはいけない。

    導出②：なぜ逆転が起こりうるのか ―― 分数の足し算の性質

    分数の不等式として書くと、正体が見える。文系で B が上、理系でも B が上、とは

    \[\frac{a}{b} < \frac{c}{d} \qquad \frac{e}{f} < \frac{g}{h}\]

    が両方成り立つことである（\(a/b\) が A の文系合格率、\(c/d\) が B の文系合格率、\(e/f\) と \(g/h\) が理系の同じもの）。ところが合算すると

    \[\frac{a+e}{b+f} > \frac{c+g}{d+h}\]

    となることがある。分数は、分子どうし分母どうしを足しても順序を保たない。 理由は、合算した率が単純平均ではなく、分母の大きさで重みづけした平均だからである。

    \[\frac{a+e}{b+f} = \frac{b}{b+f} \cdot \frac{a}{b} + \frac{f}{b+f} \cdot \frac{e}{f}\]

    この重み \(\dfrac{b}{b+f}\) が A と B で大きく違うと、層ごとの順序が合算でひっくり返る。

    数値で確かめる：本文の数値をこの形に入れると、

    \[A : \frac{140 + 24}{200 + 80} = \frac{164}{280} = 0.586 \qquad B : \frac{60 + 70}{80 + 200} = \frac{130}{280} = 0.464\]

    重みを見ると、A は受験者の \(200/280 = 71.4\%\) が受かりやすい文系。B は文系が \(80/280 = 28.6\%\) しかいない。A だけが有利な層に重みが寄っている。 層ごとの合格率では B が上（\(70\% < 75\%\)、\(30\% < 35\%\)）なのに全体で A が上に出るのは、合格率の差ではなく、この重みの差が原因である。

    逆にいえば、両アプリで学部の構成比が同じなら逆転は起きない。逆転を起こしているのは 交絡（学部）の構成比の偏り であって、アプリの実力ではない。

    使った数学：分数の加法と加重平均。確率論は使っていない。

    4. 統制すれば何でも解決？ ―― やりすぎの罠（コライダー）¶

    「手元の変数を全部統制すればいい」も誤りだ。

    交絡（共通の原因）は統制すべきだが、合流点（コライダー：2つの原因が共通して引き起こす結果）を統制すると、逆に存在しない相関を作り出す。何を統制し、何を統制してはいけないかは、変数どうしの因果の向きを考えないと決められない。

    だから因果ダイアグラム（DAG）

    「A→B」の矢印で変数間の因果の向きを描いた図を DAG という。これを描くと、どれが交絡（統制すべき）で、どれがコライダー（統制してはいけない）かが見分けられる。統制は機械作業ではなく、因果の仮説に基づく判断だ。

    導出③：コライダーを統制すると、ない相関が生まれる

    導出①は「共通の原因」を統制する話だった。ここでは「共通の結果」を統制するとどうなるかを見る。2つの原因 \(x\)、\(y\) が共通の結果 \(c\) を引き起こす構造である。

    x  →  c  ←  y
    （合流点＝コライダー）

    例を作ってみる。才能 \(x\) と容姿 \(y\) は互いに独立とし、どちらかが十分高ければ芸能界にデビューできる（\(x + y > 1.5\) なら \(c = 1\)）とする。母集団では \(x\) と \(y\) に何の関係もない。

    ところがデビューした人だけを見ると、\(x + y\) が大きいという条件がついている。すると、才能がさほどでもないのにデビューできた人は、容姿のほうが高いはずだ。逆もまた同じ。条件をつけたこと自体が、2つの間に負の関係を作り出す。

    数値で確かめる：20万人で試すと、母集団全体では \(r = -0.002\)（独立なのでほぼ 0）。しかしデビューした人（全体の 14.5%）だけに絞ると \(r = -0.686\) になる。もともと存在しなかった相関が、統制によって作り出された。

    導出①と見比べてほしい。同じ「統制」という操作が、交絡（共通原因）に対しては見せかけの相関を消し、コライダー（共通結果）に対してはない相関を作り出す。しかも \(r_{xy \cdot z}\) の計算式は、\(z\) が原因なのか結果なのかを知らないまま実行できてしまう。式の見た目からは、どちらをやっているか区別がつかない。

    だから、何を統制すべきかはデータからは決まらない。変数どうしの因果の向きについての仮定が先にあって、はじめて「これは統制すべき交絡」「これは触ってはいけないコライダー」が決まる。統制は計算ではなく、判断である。

    使った数学：条件付き確率（第2回）と相関係数。使ったのは「選抜すると条件付き分布が変わる」という一点だけ。

    今日のまとめ¶

    ポイント 中身
    疑似相関 共通原因（交絡）が作る見せかけの相関（アイス←気温→水難事故）
    統制（調整） 交絡の影響を差し引くと、見せかけの相関は消える（偏相関 r≈0）
    シンプソンのパラドックス 全体と層別で結論が逆転。正しいのは交絡で層別したほう
    やりすぎの罠 コライダーを統制すると偽の相関を作る。DAGで判断

    パートA：選択問題（各10点 ×4＝40点）¶

    A1. 「アイスの売上」と「水難事故」が強く相関する主な理由は？

    • (ア) アイスを食べると水難事故が増えるという因果がある
    • (イ) 「気温」という共通原因が、両方を同時に増やしているから（疑似相関）
    • (ウ) まったくの偶然で、再現性はない

    A2. Colabで、気温の影響を回帰で差し引いた「偏相関」を計算すると、アイスと水難事故の相関はどうなったか？

    • (ア) ほぼ0になった（見せかけの相関だった）
    • (イ) さらに強くなった
    • (ウ) 変わらず0.78のままだった

    A3. 「シンプソンのパラドックス」とは？

    • (ア) サンプルを増やすほどp値が小さくなる現象
    • (イ) 全体（合算）で見たときと、層（グループ）に分けて見たときで、結論が逆転する現象
    • (ウ) 検定を繰り返すと偽陽性が増える現象

    A4. 交絡を疑うとき「手元の変数を全部統制すればよい」と言えない理由は？

    • (ア) 統制すると必ずサンプルが減るから
    • (イ) 共通の結果である「コライダー」を統制すると、逆に存在しない相関を作ってしまうから
    • (ウ) 統制は手間がかかるから
